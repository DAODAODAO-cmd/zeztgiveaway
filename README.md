# かおかおおかおヘアゴム 抽選

ゼッツ / オメガホーン 头绳抽奖小程序。

## 文件
- `index.html` 主页面
- `support.js` 运行库（必须和 index.html 放在同一目录）
- `images/` 全部图片

## 部署到 GitHub Pages
1. 新建仓库，把本文件夹里**所有内容**（含 images 文件夹）上传到仓库根目录
2. Settings → Pages → Source 选 `main` 分支 / root
3. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`

## 概率
- ゼッツ：普通 6% ×10，ホロver. 4% ×10
- オメガホーン：N 4% ×15，R(ホロver.) 2.7% / 2.6% ×15
